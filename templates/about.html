关于 Bunfo

自动化轻小说收集与展示平台

项目简介

Bunfo 是一个开源的轻小说归档项目，使用 Scrapy 框架自动抓取 LoloBun 网站的数据，并通过 GitHub Actions 每日定时更新。所有数据均以静态 HTML 页面的形式托管在 GitHub Pages 上，无需后端服务器即可运行。

技术栈

Scrapy Python 爬虫框架，用于数据采集
Jinja2 模板引擎，生成静态 HTML
GitHub Actions 定时任务，每日自动更新
GitHub Pages 静态网站托管

功能特性

  • 每日自动抓取最新轻小说数据
  • 支持按类型浏览（魔法、都市、游戏等）
  • 全文搜索功能，支持标题、类型、标签
  • 响应式设计，适配桌面与移动端
  • 深色/浅色主题切换
  • 图片懒加载，优化性能

数据来源

所有小说数据来源于 LoloBun，仅供学习交流使用。如有侵权，请联系删除。

开源地址

本项目完全开源，欢迎访问 GitHub 仓库 贡献代码或提交 Issue。
